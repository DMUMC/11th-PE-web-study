# 7주차 JWT 검증

- Gradle 통합 테스트 33개 통과: 토큰 정상·누락·변조·만료, 로그인 실패 응답 통일, 자기 닉네임 유지·타인 중복, memberId 위조 차단, CORS 사전 요청 및 기존 회귀 테스트.
- 실제 MySQL + Postman: 로그인 200, 내 정보 조회·수정 200, 본인 평점 등록 201, 중복 등록 409, 본인 수정 200, 타인 수정 403, 토큰 누락·변조 401, 없는 평점 삭제 404, 본인 삭제 200.
- 존재하지 않는 이메일과 틀린 비밀번호 모두 AUTH401_1 및 동일 메시지 확인.
- 프론트 pnpm build(Vite + TypeScript) 통과. Vite /api 프록시를 통한 실제 JWT 로그인·내 정보 조회도 각각 200 확인.
- 실제 캡처는 별도 작업 폴더에 보관하고 Notion 실습·필수 미션에 첨부합니다. 실제 액세스 토큰을 포함하므로 저장소에는 넣지 않습니다.
