# UMCine 8주차 Frontend

밀러의 「TanStack Query로 서버에 데이터 요청하기」 실습입니다. 영화 정보는 TMDB에서 조회하고, 회원 정보·즐겨찾기·평점은 같은 주차의 [Spring Boot 서버](../backend/README.md)에 저장합니다.

## 실행

1. 백엔드 README를 따라 demo 프로필로 서버를 실행합니다. 기본 주소는 `http://127.0.0.1:8088`입니다.
2. 이 폴더에서 의존성을 설치하고 환경 설정 파일을 준비합니다.

   ```sh
   pnpm install --frozen-lockfile
   cp .env.example .env.local
   ```

3. `.env.local`의 `VITE_TMDB_READ_TOKEN`에 본인의 TMDB 읽기 토큰을 입력합니다. 백엔드 주소가 다르면 같은 파일의 `UMC_BACKEND_URL`도 변경합니다.
4. `pnpm dev`를 실행하고 `http://localhost:5179`를 엽니다. Vite는 `/api` 요청을 백엔드로 전달합니다. 개발 서버와 미리보기는 모두 백엔드가 허용하는 5179 포트를 사용합니다.

`pnpm build`로 라우트 생성, 프로덕션 번들링, TypeScript 검사를 실행합니다.

## 화면에서 확인하기

| 화면 | 확인할 동작 |
| --- | --- |
| 회원가입 · 로그인 | 회원가입하고 로그인하면 홈으로 이동하고, 헤더에 로그인한 회원 정보가 표시됩니다. |
| 마이페이지 · 내 정보 수정 | 로그인 전에는 로그인 화면으로 이동합니다. 로그인 후 프로필을 수정하면 헤더와 마이페이지에서 변경한 정보를 확인할 수 있습니다. |
| 영화 상세 | 즐겨찾기를 등록·해제하고, 1~5점 평점을 등록·수정·삭제할 수 있습니다. |
| 마이페이지 | 영화 상세에서 즐겨찾기한 영화를 확인할 수 있습니다. |

로그인 후 회원 정보를 다시 조회할 때는 `invalidateQueries`를 사용합니다. 프로필 수정에 성공하면 `PATCH /members/me` 응답으로 `setQueryData`를 호출해 즉시 화면을 갱신합니다.
