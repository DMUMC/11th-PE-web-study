# 트러블슈팅 1 — Git 제출 목록에서 실행 필수 파일 누락

## 문제

구현과 테스트를 마친 뒤 `git status --short --untracked-files=all`로 제출할 파일을 확인했는데, 로컬에 존재하는 `gradle/wrapper/gradle-wrapper.jar`와 `sql/01-schema.sql`이 목록에 나타나지 않았습니다. 이 상태로 올리면 다른 환경에서 Gradle 실행이나 DB 초기화를 재현할 수 없습니다.

## 원인 확인

`git check-ignore -v gradle/wrapper/gradle-wrapper.jar sql/01-schema.sql`을 실행했습니다. 상위 저장소 `.gitignore`의 `*.jar`, `*.sql` 규칙이 두 파일을 제외하고 있었습니다. 로컬 테스트 성공만으로 Git 제출 파일이 완전하다고 판단할 수 없었습니다.

## 해결

6주차 백엔드 `.gitignore`에 다음 예외만 추가했습니다.

```gitignore
!gradle/wrapper/gradle-wrapper.jar
!sql/01-schema.sql
```

빌드 결과 전체나 다른 주차의 파일을 추가하지 않고, 이 프로젝트를 재현하는 데 필요한 두 파일만 포함했습니다.

## 검증

두 파일이 `git ls-files --others --exclude-standard`의 제출 후보 목록에 나타나는지 확인했습니다. `.env`, `.gradle`, `build`, `logs`는 계속 제외됩니다. 커밋·푸시는 아직 실행하지 않았습니다.
