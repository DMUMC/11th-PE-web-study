## 확인한 동작

- 회원가입 201, bcrypt 60자 해시 저장 및 matches 검증, 비밀번호 응답 제외
- 이메일·닉네임 중복 409 및 저장 건수 유지
- 비밀번호 구성, 이메일 형식, 닉네임 길이, bcrypt UTF-8 바이트 제한 검증
- 평점 등록 201 → 수정 200 → 조회에 수정 반영 → 삭제 204/빈 본문 → 빈 목록
- 중복 평점 409, 다른 회원은 같은 영화에 별도 등록 가능
- 잘못된 별점, 소수 movieId/score, 누락 score, 501자 후기 400
- 다른 회원의 수정·삭제 403, 없는 평점의 수정·삭제 404
- JSON/경로 타입 오류의 공통 응답
- 서비스 중복 검사 없이 직접 저장해도 DB UNIQUE가 이메일·닉네임·회원+영화 중복 거부
- 동시 회원가입 두 요청: 201 한 건, 409 한 건, 저장 회원 한 명
- 기존 조회 API와 CORS 회귀 검증, POST/PATCH/DELETE preflight 허용

## 직접 실행 및 캡처

README 순서로 MySQL과 서버를 준비한 뒤 Postman 요청 모음을 위에서 아래로 실행합니다. 01 회원가입, 04 검증 실패, 06 평점 등록 또는 12 평점 수정 화면에서 요청 JSON·HTTP 상태·응답 JSON을 캡처하면 됩니다. 추가로 07 중복 평점, 10/11 소유권 오류, 14 삭제 204, 16/17 없는 평점 결과를 확인할 수 있습니다.

Postman 요청 모음은 JSON 문법과 요청 순서를 검토했으며 실제 Postman 앱 실행 결과를 대신하지 않습니다. API 예시는 실제 실행 캡처가 아닙니다.
