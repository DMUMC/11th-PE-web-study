# UMC 워크북 매주 할 일 정리

> 워크북: 권이의 워크북 (Notion) — https://app.notion.com/p/makeus-challenge/3d7b57f4596b80f39193d9e0b94c9b12
> 주차별 페이지는 `🌐 N주차` 아래 **Frontend / Backend** 두 개씩 있음

---

## 1. 매주 흐름

1. 워크북에서 해당 주차 **Frontend / Backend** 페이지 열기
2. 본문 실습 진행 → 로컬 `weekNN/front`, `weekNN/back` 에서 구현
3. 페이지 하단 **🔥 미션** 수행 (필수 → 선택)
4. **💪 미션 기록** 작성
5. 페이지 노션 링크를 **umc.ai.kr** 에 제출

> **실행할 때는 MCP를 사용해서 브라우저를 열어 실행한다.**
>
> **MCP 사용 구분**
> - **Notion 워크북 읽기** → 크롬 확장 MCP(`claude-in-chrome`)로 노션 페이지를 열어서 읽는다.
> - **테스트(앱 실행 확인)** → 로컬 MCP(`browser`)로 브라우저를 열어 로컬 서버(front/back)를 확인한다.

---

## 2. 매 주차 채울 칸

### 🔥 미션
- **(필수)** 미션 — 반드시 수행
- **(선택)** 미션 — 여유 있으면 수행
- 미션마다 **제출물**(캡처/코드 등)과 **확인 포인트**가 적혀 있음 → 그대로 맞춰서 준비

### 💪 미션 기록
- 페이지의 `미션 기록` 토글 안에 작성하거나, 새 페이지를 만들어 작성
- 중간 과정 없이 **결과만** 기록 (미션 제출물: 캡처 / 핵심 코드 / 최종 확인 결과)
- Frontend는 `필수 미션` / `선택 미션` 토글로 나뉘어 있음 → 각 토글에 결과 기록

## 3. 파트별 미션 구성 (예시: 6·7주차)

### Backend
- Spring Boot / NestJS 중 **본인 스택 1개**로 구현
- 미션 위쪽에 `✅ 실습 체크리스트`, `☑️ 실습 인증` 이 있고, 미션 제출물은 보통 **Postman 요청/응답 캡처**

| 주차 | 필수 미션 | 선택 미션 |
|---|---|---|
| 6주차 - 입력한 데이터를 저장하기 | 회원가입 + 평점 등록/수정/삭제 API, 실패 응답 일관 처리(409/400/403/404)<br>제출물: API 명세, 요청/응답 캡처, 핵심 코드 링크, 트러블 슈팅 1건 | 이메일/닉네임 중복 code 분리, DB UNIQUE 위반 전역 예외 처리 |
| 7주차 - 로그인한 사용자를 구분하기 | 실습 1~6 + Postman 9단계 시나리오<br>제출물: 로그인 성공, 토큰 없이 401, 남의 평점 수정 403, 본인 평점 등록 201 캡처 | 토큰 만료(AUTH401_4) 체험, `@LoginMember` 어노테이션 |

### Frontend
- 미션 제출물은 보통 **화면 결과 + 핵심 코드**

| 주차 | 필수 미션 | 선택 미션 |
|---|---|---|
| 6주차 - TanStack Query로 서버 데이터 조회하기 | 목록/검색/상세를 TanStack Query로 전환, 로딩·오류·빈 결과·성공 상태 표시, Query Devtools·Network로 캐시 확인 | — |
| 7주차 - 인증 개념 이해와 회원가입 구현하기 | 로그인 / 내 정보 조회 / 내 정보 수정 화면 퍼블리싱 | 내 정보 페이지 폴더 구조 설계 |

## 5. PR 올리기 & PR 이후 할 일

### PR 올리기
| 항목 | 내용 |
|---|---|
| 리포지토리 | `DMUMC/11th-PE-web-study` |
| 브랜치 | `weekNN_gwoni` → `main` |
| 제목 | `[weekNN] 권이 N주차 미션` |
| 본문 | `.github/PULL_REQUEST_TEMPLATE.md` 형식 — **구현 내용 / 실행 화면 / 느낀 점** |
| 커밋 메시지 | `feat:` / `refactor:` / `chore:` / `docs:` + `weekNN ...` |

> 제외할 것: `node_modules/`, `build/`, `dist/`, `.env.local` (gitignore 처리됨)

### PR 이후 할 일 (노션: 미션 제출 안내 & CodeRabbit 사용법)
1. **CodeRabbit 리뷰 확인** — PR을 만들고 조금 기다리면 CodeRabbit이 PR 요약과 코드리뷰 코멘트를 자동으로 남김
   - 리뷰 코멘트 확인 → 필요한 것만 반영해서 커밋
   - 궁금한 점은 PR 코멘트로 `@coderabbitai` 에게 질문 가능
   - 다시 리뷰받고 싶으면 코멘트에 `@coderabbitai review`
2. **Rate Limit 주의** — 시간당 PR 리뷰 수 제한(개발자당 3~5회) 있음
   - 커밋을 여러 번 한 뒤 PR을 한 번 만들면 1회로 처리
   - PR을 만든 **뒤에** 커밋할 때마다 리뷰 1회씩 차감 (`auto_incremental_review: true` 인 경우)
   - → 커밋을 모아서 PR 생성, 수정 커밋은 몰아서 push
3. (선택) **CodeRabbit 커스텀** — 리포 루트에 `.coderabbit.yaml` (예: `language: "ko-KR"`, `reviews.profile: "chill"`) / CodeRabbit 페이지에서도 설정 가능
4. **노션 미션 기록 작성** — 미션 제출물(캡처/핵심 코드/결과)을 `미션 기록` 토글에 정리
5. **umc.ai.kr 제출** — 노션 페이지 링크 제출 (위 4번 절차)
6. (선택) **블로그 챌린지** — 가이드라인 카테고리 중 1개로 블로그 작성 → 노션 폼에 URL 제출 시 상점 +3 (주 1회)
