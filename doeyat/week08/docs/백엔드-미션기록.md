# 8주차 백엔드 미션 기록

모든 신규 API에 Authorization: Bearer {token} 헤더가 필요하다. memberId는 요청으로 받지 않고 토큰에서 가져온다.

| Method | URL | 입력 | 응답 |
| --- | --- | --- | --- |
| POST | /favorites | {"movieId":238} | 201, favoriteId/movieId/createdAt |
| GET | /favorites | 없음 | 200, 내 목록 최신순 |
| GET | /favorites/238 | 없음 | 200, movieId/isFavorite |
| DELETE | /favorites/238 | 없음 | 200, 공통 응답 |
| POST | /movie-records | {"movieId":238,"score":5,"comment":"다시 보고 싶어요","addToFavorites":true} | 201, rating/favorite |

중복 즐겨찾기: 409 FAVORITE409_1. 없는 즐겨찾기 삭제: 404 FAVORITE404_1. 잘못된 movieId: 400. 토큰 누락: 401 AUTH401_2. 빈 목록·미등록 상태는 정상 200이다.

Favorite은 BaseTimeEntity를 상속하고 회원과 영화 ID 조합에 UNIQUE 제약을 둔다. FavoriteService는 회원별 조회·삭제를 수행한다.

MovieRecordService.create의 @Transactional 안에서 평점과 즐겨찾기를 저장한다. 두 번째 저장이 실패하면 먼저 저장한 평점도 롤백한다.

이 프로젝트의 AuthConfig는 보호 경로를 열거하므로 신규 경로도 추가했다.

H2·MockMvc 통합 테스트 통과. 토큰 누락, 즐겨찾기 중복, 미등록 상태, 삭제, 영화 기록 동시 저장 및 중복 즐겨찾기 실패 시 평점 롤백을 검증했다. Postman 캡처는 아직 생성하지 않았다.
