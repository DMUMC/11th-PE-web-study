실제 API 확인 당시 인기 영화 페이지당 20개, ‘스파이더맨’ 검색 14개, 결과가 없는 검색 0개를 받았습니다. 이 개수와 영화 순서는 TMDB 데이터 변경에 따라 달라질 수 있습니다.

검증한 URL:

- `/`
- `/?page=2`
- `/search`
- `/search?query=스파이더맨`
- `/search?query=umcine-no-results-93d6e845`
- `/movies/155` (목록 응답에서 얻은 실제 TMDB ID)

자동 테스트는 기본 URL/한국어/인증, 검색어 인코딩, 목록을 거치지 않는 상세 요청, 검색 URL 복원과 새 라우터에서의 재요청, 빈 검색어의 요청 생략, 빈 결과, 잘못된 ID, HTTP 오류, 오프라인 오류, 요청 취소, 페이지 범위 정리, 성공·빈 결과·오류 화면 렌더링과 TMDB 출처를 검증합니다. 테스트에서는 가짜 응답을 사용하고, `check:tmdb`에서는 실제 응답을 사용합니다.

## 남은 브라우저 수동 확인

브라우저 연결 도구가 사용 불가능했고, Windows Computer Use 도구도 현재 브라우저 URL을 충분히 확실하게 판별하지 못해 안전 정책에 따라 중단되었습니다. 이후 UI 입력은 수행하지 않았습니다.

따라서 아래 항목은 완료로 표시하지 않았습니다. Node 서버 렌더링·HTTP 검증은 브라우저의 실제 동작·시각 검증을 대신하지 않습니다.

- `/fetch-check.html`에서 버튼을 한 번 누르고 DevTools Network의 실제 요청·응답 확인
- 실제 브라우저에서 각 URL 직접 접근·새로고침, 페이지 이동과 검색 입력 확인
- 느린 네트워크에서 스켈레톤, Offline에서 오류와 복구 후 재시도 확인
- 북마크 클릭·저장과 브라우저 새로고침 후 복원 확인
- 정상 이용 상태에서 Console 오류·경고가 없는지 확인
- 참고 디자인과 화면 비교, 모바일·태블릿·데스크톱 레이아웃 확인

구체적인 실행 및 확인 순서는 [README.md](./README.md)에 있습니다.
